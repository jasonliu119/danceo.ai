# AI Cat Dance Video Ideas

Create a cat dance concept by pairing a clear cat image or original character with an authorized movement reference. The image establishes the subject; the video guides the rhythm and motion.

## Three concepts to try

1. **Simple groove:** start with a centered character and a short reference with easy-to-read gestures.
2. **Expressive character:** use original illustrated cat artwork with a visible face and body, then test a reference that suits its personality.
3. **Full-body move:** choose a character image and reference where the body stays visible throughout the intended movement.

Simple backgrounds and stable reference footage make it easier to evaluate a first result. If a clip is unclear, change one input and compare another version; results can vary.

## Before generating

Use a photo, artwork, and reference video that you have permission to transform. Preview the inputs and check the displayed credit cost before starting. Consider the context and rights involved before sharing the generated clip.
